## 🚩 2026-10-14 下午：音樂一直跳回海浪（真正的原因）
- 使用者給了螢幕錄影（2026-10-14 下午1.52.48）：人在 1 樓圖書館區（D），選 Lofi 在播，頁面重新載入後播放器變回「海浪」；設定裡「預設音源」是海浪、「進頁自動播放」開著。
- 原因：`useAmbientAudio` 有個 `watch(defaultAudioTrack)` 會把選的曲目換成預設。`loadAudioPreferences` 把 `defaultAudioTrack` 從初始值 `lofi` 改成存的 `ocean`，
  watch 就觸發 → 每次載入都把選的曲目蓋掉。上午那個「分區音樂只在播時才換」的修正沒錯，但不是這個現象的主因。
- 修法：拿掉 watch；設定面板改預設音源時呼叫 `setDefaultTrack`（設預設＋換過去）。本機 dev server 用 chrome-devtools 測過重新整理後保留 Lofi。
