# 架構細節（How it fits together）

> 從 `CLAUDE.md` 搬出來的（2026-10-12，內容原封不動）。`CLAUDE.md` 每個 session 都會整份載入，這份不會——
> **要動某一塊之前，用關鍵字 grep 這份找到那一段再讀**（例如 `grep -n "YouBike\|F1\|POS\|Google login" docs/ARCHITECTURE.md`）。
> 改了那一塊的行為，記得回來更新對應的那一條。

- **`pages/IndexPage.vue`**: seat selection, the connection flow, and a fixed bottom dock holding the timer (`FocusClockPanel`, settings in a dialog) and `AmbientAudioPlayer`, so the map gets the full width. Room = `{floor}-{zone}` (`2-A`), seat = `{room}-{NN}`. On mount and on floor/zone change: seat snapshot (REST) → WS token (REST) → WebSocket; `connectionVersion` drops callbacks from superseded attempts. Networking lives in `pages/index/composables/useLibrarySocket.ts` + `pages/index/actions/`.
- **Identity**: `userId` is per browser (`localStorage['lib_uid']`; the backend only accepts `[A-Za-z0-9_-]`, so old ids like `使用者_123` are replaced on load); the per-tab id (`sessionStorage`) is sent as `sessionId` and is what owns a seat server-side. Two tabs of one user may hold different seats on purpose — don't add a single-tab lock.
- **Seats are only released by moving or disconnecting** (no "leave" message). Standing up keeps `selectedSeatId`; the seat just glows as reserved.
- **Remembered across visits** (`localStorage`): last seat, last floor/zone (`focus_island_last_location_v1`), and the avatar's standing position (`focus_island_player_position_v1`, written by the scene). On load: seated → sit back; standing → stand at the same spot while the seat is still auto-reserved.
- **Seat scene (`pages/index/components/SeatScenePixel.vue`)**: Gather-style top-down pixel library on a 2D canvas. Emits `select`, `change-floor`, and `webgl-failed` (→ `IndexPage` falls back to `SeatGrid`).
  - `pixel/pixelMap.ts` (pure): tile coords, 1 tile = 16px; seat slots with a `facing`, props, rugs. **Every map is a place to sit and focus**: a zone has `SEATS_PER_ZONE` = 72 seats in a fixed order — library 18, then 101 (6), zoo (6, now its own map — `offMap` here), Shilin night market (12, now on its own map — `offMap` slots here), beach (8), and the F1 stand (22, drawn by `F1Scene`, indices from `F1_SEAT_START`; it is the last block, so new F1 seats can simply extend it). Seat NN ↔ slot index, so never reorder; append new seats at the end and bump the backend's `seatsPerZone`. Auto-seat on load only picks library seats.
  - `pixel/pixelArt.ts`: Kenney Roguelike Indoors (CC0, `public/pixel/`) for chairs/tables/plants; floor, walls, shelves, stairs, TV, rugs, beanbags, armchairs and avatars are painted in code. Avatars use a swappable palette (`AvatarColors`).
  - `pixel/pixelThemes.ts`: the zone picks the look (`themeForZone`: A forest, B café, C deep-sea cabin, D/unknown library). Themes only re-skin floor, walls, back-wall decor, the TV spot, plants and small props plus per-frame ambience — seat slots and collision are shared, so a new theme never touches navigation. Zone ids/names come from the backend's `zoneDefs`; `zoneLocaleMap` in `useLibrarySocket.ts` translates them.
  - Collision + A* in `composables/seatNavigation.ts` (pure, tile units; its `z` is the map's `y`).
  - Static layer painted once per map build; props/seats/player Y-sorted each frame; integer scale (3× ≥900px wide, else 2×) with a follow camera; name pills drawn in screen space.
  - Every room has the same beach below the library's front wall — through a glass door on the lowest floor, down an escalator on the floors above (`map.beach.escalator`) (`map.libraryHeight` is where it starts; `map.height` includes it). The minimap (button / `M`) redraws the static layer scaled down each frame while open; clicking it walks there.
  - Floor changes: stairs (adjacent floor) or the elevator on the back wall (any floor, picked from a panel). Both set `pendingSpawn` and emit `change-floor`.
  - **Outdoor world** (`pixel/pixelWorld.ts`, `map.world`): the library sits at (0,0)–(32, libraryHeight); around it are Taipei 101 (x < 0), the zoo (x ≥ 32), Shilin night market (y < 0, through the back-wall door `BACK_DOOR`) and the beach below, all one seamless map with **negative coordinates**. The static layer covers `world.x0..x1 × y0..y1` and is painted with a translated origin; camera, minimap and lighting use the world rect. Walkers (people, taxis, animals) are deterministic functions of time (`walkerPose`), so they need no state or network.
  - YouBike stations (`youbike` props in `map.world`): E or click at a station rents a bike (a new `VehicleState`), dismounting next to any station returns it (removed from `vehicles`). Bikes may ride anywhere on land. At most 10 rented bikes exist at once (`MAX_RENTED_BIKES`); a vehicle left unridden for 3 minutes is reclaimed (`returnIdleVehicles`: rented bikes vanish, the cart and boat go back to `home`). Vehicles are per-browser, not shared. Floor lying (`lieOnFloor`, L / E with nothing nearby / tap yourself) is library-only and shared via `POS` `pose: 'floor'`.
  - **Starting focus uses the seat you're at**: `toggleFocus` asks the active scene (`seatForFocus()` via a template ref) first. Seated / mid-sit / walking to a seat / standing next to an empty one → that seat is claimed (`claimSeat`, no `isSwitching` guard). Lying on a beanbag, lounger or the floor → `'lying'`: you stay there and the reserved seat is kept. Anything else (standing in the open, riding, swimming) → `null`: a focus you start yourself is refused with `notifyNotSeated` (since 10-15; it used to snap you to the reserved seat). Automatic starts (`toggleFocus('auto')`: group-focus rounds, resuming a previous session) still use the reserved seat.
  - **Leaving during focus asks first**: while focusing, a direction key, Space/E/L, the joystick, or a click on the map / minimap (other than a person or your own seat) opens `LeaveFocusDialog`. Choosing "End and leave" emits `end-focus` (`IndexPage.endFocusToLeave` stops the timer), then the click that triggered it is replayed. Cancelling drops it. Same in `F1Scene`.
  - **Keys go back to the map from outside controls** (`keyBelongsToPage`, same in `F1Scene`): after clicking a button, tab or the volume slider outside the scene, focus stays there; Space and movement keys (`KEY_MAP`) blur it and go to the scene, Enter still activates it. Text inputs, `textarea`/`select`, contenteditable and dialogs keep all their keys (range and checkbox inputs do not).
  - **Share my spot** (`shareLocation.ts`, header button `📍 分享位置`): builds `?meet={floor}-{zone}&scene=library|f1|park&x&y&n={name}` from the active scene's `positionForShare()`; on touch devices it uses `navigator.share`, otherwise the clipboard. On load `IndexPage` calls `takeSharedLocation()` (then strips the params from the URL): floor/zone and `sceneLocation` come from the link; for the library map it rewrites `focus_island_player_position_v1` to one tile right of the sharer so the scene's normal standing-position restore puts you there; F1 / park read `takeArrival()` once on mount. A toast says whose side you arrived at. Local only — nothing goes through the backend.
  - **Presence on F1 / park** (since 10-16, `sceneRemotes.ts`): POS carries `scene: 'f1' | 'park' | 'beitou'` (backend `allowedScenes`; F1 driving adds `vehicle: 'f1'` + `angle`). The main map skips remotes with a `scene`; F1Scene / RiverParkScene send their own POS through `createPositionSync` (same throttling as the main map, `hidden` while seated) and draw same-room remotes on their map via `createRemoteView` (eased, 💤 after 1 min): walkers, park YouBike riders, F1 cars in a colour derived from the name.
  - **Riverside park** (`components/RiverParkScene.vue`, modelled on Toyama's Fugan Canal Kansui Park): a separate map like F1, reached from the MRT panel (`goPark` → `go-park`; the MRT panel now always opens so the park is reachable even with one zone). Seats 73–88 (`PARK_SEAT_START`/`PARK_SEAT_COUNT`): north-bank benches 4, café terrace 4, south-bank benches 8. An east–west canal is crossable only on the Twin Tower Bridge deck; click-to-walk routes over the bridge (`planRoute`). Season toggle Sakura / Snow (top-right, `focus_island_park_season_v1`, default by month: Dec–Feb snow) repaints the ground and switches trees, falling petals/snow and ice floes. Same dawn/day/dusk/night phases as the main map (`lightPhase`). The lakeside café (`pixel/parkCafe.ts`: flat roof, floor-to-ceiling glass, leopard-cat badge, terrace deck) has a barista at the door: walking up opens a drink menu paid with focus coins (held drink shown for 3 min, local only). Two YouBike racks (`BIKE_STATIONS`): rent / ride / park / return, one bike, local only. Sitting on a park seat on load or when focus starts switches `sceneLocation` to `park` (`isParkSeat`).
  - **Beitou hot springs** (since 10-16, `components/BeitouScene.vue`): same pattern as the park, MRT panel → `goBeitou` → `go-beitou`. Seats 89–104 (`BEITOU_SEAT_START`/`BEITOU_SEAT_COUNT`, last block; backend `seatsPerZone` = 104): Beitou Library porch benches 4, creek foot bath 4, open-air bath 8 (soakers drawn head-only with a towel; empty spots are submerged stepping stones). Beitou Creek runs north–south, crossable only on two red bridges (`planRoute` picks the nearer). Also Xinbeitou station (return trigger), Hot Spring Museum, Thermal Valley (fenced), stone lanterns lit at night, steam puffs. Share links / arrival use `scene=beitou`; `isBeitouSeat` switches `sceneLocation`.
  - **F1 circuit** (`components/F1Scene.vue`): a separate map reached via the F1 platform (F1 line on the station panel → `go-f1`). `IndexPage` swaps scenes via `sceneLocation`; starting focus sends you back. Going there sends a `hidden` POS so others don't see you frozen at the station. One drivable car (heads where you point, slow off-track), NPC cars on the centreline, lap/best times (best in `focus_island_f1_best_v1`).
  - The elevator panel also lists the floor's zones (`rideElevatorToZone`, arrive at that zone's elevator); keyboard: digits = floor, Z/X/C/V = zone (only while the panel is open, so digits don't emote then). It opens even with one floor when there are several zones.
  - **Fishing** at the goldfish pool on the Shilin map's temple square (`ShilinScene`, the panel opens when you stand below the pool; E casts/pulls): `castLine` costs `FISHING_PRICE` (20), the float dips after 1.5–4s and `pullLine` must land within 1.2s; the catch (`FISH`: goldfish 70% / tropical 25% / pufferfish 5%) becomes the held item (ids are in the backend `allowedShopItems`).
  - Zone changes in the scene happen at the MRT station in the 101 area (`world.mrtTrigger` → panel → `change-zone`; you arrive at the station). The left/right wall doors now lead outdoors.
  - Emotes (bottom-left buttons, `H` / `1`–`4`): a fixed set (`EMOTE_IDS`, mirrored by the backend's `allowedEmotes`) sent as an `EMOTE` WS message. Others only see a bubble over the sender's **seat**, since standing positions aren't shared. Beachgoers and `demo_` bots within a few tiles reply locally.
  - Vehicles (`map.vehicles`, art in `paintVehicle`): bike indoors, cart on deck/sand, boat at sea. `vehicleArea` limits where each can go; `canOccupy` swaps in for `nav.isBlocked` while riding. The boat has inertia (`updateBoat`) and you can only get off near the shore. Riding is local only, like walking; the scene drops you off when focus starts or the map rebuilds.
  - Lighting follows the browser's local time when pref `sceneClock` is on (`lightingNow`: dawn 05:00–08:00, day 08:00–15:00, dusk 15:00–18:00, night otherwise), otherwise the site theme. At night the outdoors get an extra multiply (`OUTDOOR_NIGHT_TINT`, library rect excluded) so street lamps (`streetLamp`: 101 sidewalks, zoo path, beach deck) and the night-market lantern strings (`lanternString` between `lanternPole`s) stand out. Rain (`drawRain`) shows while the `rain` track is playing.
  - Clicking another person opens a profile card (`pickPerson`); `todayMin`/`streak` ride along in `MOVE`/`JOIN`/`POS` like the look fields.
  - Touch devices get a joystick (`stick`, merged with the arrow keys in `updatePlayer`). First visit shows a 4-step tour (`focus_island_tour_done_v1`).
  - Standing/riding positions are shared via `POS` (throttled to ~7/s while moving, a 20s keepalive, `hidden` when you sit). Not stored server-side: a new peer's `JOIN` bumps `peerJoinedAt` so everyone re-sends. Remote players are played back 260ms late along the received points (`remoteTracks` → `remoteShown`, with `moving`/`facing` derived from the path), so walking is even and legs stop at the last point; jumps > 6 tiles snap. Dropped after 45s of silence. Sends respect the 0.15s interval even for the stop update; the backend never drops `moving: false`/`hidden` POS (min interval 50ms otherwise). The seat itself still goes through `MOVE`.
- **YouTube wall TV** (`composables/useYouTubeTv.ts`, `components/YouTubeTv.vue`): the themed TV spot (`map.tv`: library TV / forest waterfall / café chalkboard / deep-sea console) carries a "▶ Play YouTube" pill while no video is showing (`showing`), and clicking inside `pixelArt.tvScreenRect` emits `open-tv` → `AmbientAudioPlayer.openYouTube()` (switches to the `youtube` track and opens the link field; works during focus too). the `youtube` track plays a pasted YouTube video/playlist link (IFrame Player API, loaded on first play) — local only, nobody else sees it. One player for the whole page, teleported to `body` (the page wrapper has a transform). `SeatScenePixel.reportTvScreen` writes the wall TV's on-screen rect (16:9, sized to `map.tv`, overlapping the brick above) into `tvScreen` every frame; when the whole TV is on screen and the minimap is closed the iframe sits on the TV, otherwise (walked away, outdoors, F1, minimap) it moves to a bottom-right mini window above the dock, which can be minimized to just its title bar (`minimized`; video 0px tall, audio continues). While the scene is loading (floor/zone switch) it is hidden with `clip-path` (never removed — removing the iframe would reload it). It can be expanded to a centred window. On phones / narrow screens (`(pointer: coarse), (max-width: 767px)`) there is no corner window: the video stays on the TV clipped to the map (`clip-path`), hidden when the TV is fully off screen, the minimap is open, the map is rotated or on F1/park. The TV overlay ignores pointer events (except its expand button) so it never swallows taps on the map's buttons. YouTube's rules require the player to stay visible, so it is never audio-only. `useAmbientAudio` treats it like a track (play/pause/volume via `getTrackVolume() * 100`, loop, media session title); actual playing state comes from the player's state events. Zone tracks never replace it. Clicking the video would steal the keyboard, so a window `blur` hands focus back. Not offered in `WidgetPage` (no TV mounted → `hostMounted` false). Saved link + last 5 titles in `focus_island_youtube_v1`.
- **Watch YouTube together** (`composables/useWatchTogether.ts`, `components/WatchTogetherBar.vue`, WS `WATCH`): while playing a video on the TV, "👥 Invite this room to watch" in the music settings makes you the host: you send `{v, t, playing}` (11-char video id, seconds, play state; no text) on start, on play/pause, when someone joins the room and every 10s; `{stop}` when you stop, switch track, close the TV or change room. Others in the same room (floor-zone) get a small card above the dock with the name and the oEmbed-fetched title — **nothing plays until they press "Watch together"**. Hidden when the sender is blocked (`prefs.blocked`), DND is on, or `prefs.watchInvitesOff`; "No thanks" hides that host+video. Following: `audio.playSharedYouTube` loads the video at the host's second (cued if the host is paused), host play/pause is mirrored, drift >4s is seeked, a viewer's own pause isn't overridden until the host toggles again. "Leave" stops the video and restores the previous track. No message for 35s = host gone. Video changes are ≥30s apart (backend drops faster ones, host retries on the next heartbeat); every message ≥1s apart. Room-scoped — except at home (own or a friend's, v1.16.0): the backend sends a home's `WATCH` only to that home with `home: true`, the client only accepts `home` invites while `sceneLocation === 'home'` (`atHome`) and vice versa, `roomKey` becomes `home:<owner>`, and `HOMEJOIN` bumps `peerJoinedAt` so the host re-sends. Labels switch to "Invite everyone here".
- **Swimming**: walking (or clicking) into the sea is allowed for people on foot (`inSea` in `canOccupy`; a click into the sea walks to the shore then swims straight). Deeper than `seaTop + SWIM_DEPTH` you swim: slower (`SWIM_SPEED`), only the top `SWIM_ROWS` of the avatar above a waterline with splashes (`drawSwimmer`). Others are drawn swimming from their position alone, so no extra WS data is needed (the backend also accepts `pose: 'swim'` since 10-15, unused). Getting off the boat far from shore drops you into the water.
- Speech bubbles are clamped inside the canvas (`drawBubble`), e.g. bubbles near the top edge of the map.
- **Audio** (`composables/useAmbientAudio.ts`, `synthAmbience.ts`): tracks with a `synth` field are generated with Web Audio; the rest are mp3s in `public/music/`. `beats` (lo-fi) and `chiptune` are generative music. A second synth player is the **scene ambience** layer (`SoundscapeKind`: beach / city / market / zoo / f1): `SeatScenePixel` emits `area`, `IndexPage` maps it (F1 scene → `f1`, library → none) to `audio.setSoundscape`. It has its own toggle + volume, starts only after the first user gesture, and is independent of music play/pause. The zone's own track (`playZoneTrack`) is applied only when the zone actually changes (the `[currentFloor, activeZoneId]` watch in `IndexPage` compares the previous zone) — loading the page or changing floor keeps the track the user picked. It also only switches while music is playing; when paused the selection is left alone, so starting focus (follow-focus playback) never plays a track the user didn't pick. The settings panel's default track goes through `setDefaultTrack` (not a watch), because loading prefs also writes `defaultAudioTrack` and must not override the selected track.
- **Focus together** (`composables/groupFocus.ts`, pref `groupFocus`): clock-aligned rounds, 25 min from every :00/:30 then a 5 min break. No server state; `IndexPage` checks each second, joins mid-round via `store.alignTimer`, and won't re-start a round the user stopped. Auto-restart is ignored in this mode.
- `WidgetPage.vue` (iframe embed) reuses `FocusClockPanel` + `AmbientAudioPlayer` inside one panel — keep both components layout-neutral (no fixed positioning).
- **Focus coins** (pref `coins`, starts at 300 since 10-16; older players are topped up to 300 once via `applyCoinFloor` / `coinFloor300`, also after a cloud merge): +1 per focused minute while the timer runs (`IndexPage` watches `todayFocusedMinutes`). Spent at the Shilin and Miaokou maps' stalls and shops (`pixel/shilin.ts`, `pixel/miaokou.ts`; new item ids must be added to the backend `allowedShopItems` first or the whole POS is dropped); the bought snack is held for 3 min and shared via `POS` `item` — while seated the hidden POS carries it and others draw it beside the seat (`seatedItems`), while riding it is drawn above the handlebar.
- Browser notifications (`composables/focusNotify.ts`, pref `notifications`) fire only while the tab is hidden; permission is requested from the toggle's click.
- **Google login** (`composables/useAccount.ts`, button in `SettingsPage`): optional. On login the cloud copy is merged in (prefs: cloud wins; progress: max per day / max totals), uploaded, `lib_uid` becomes `g_<id>` and the page reloads so the socket identity matches. `MainLayout` calls `startSync()`; changes upload debounced 15s plus a `keepalive` PUT on `pagehide`. Logout keeps local data and switches back to a random `lib_uid`.
- **Timer** (`stores/pomodoro.ts` + `workers/timer.worker.ts`): countdown runs in a Web Worker so background tabs aren't throttled; today's stats reset by local date.
- **Player prefs** (`composables/usePlayerPrefs.ts`, one shared ref in `localStorage`): daily goal (header progress), avatar palette indices (`LOOK_HAIRS`/`LOOK_SHIRTS` in `pixelArt.ts`) and do-not-disturb. Look + DND ride along in every `MOVE`/`JOIN` payload (`readerExtras` parses them); changing them while seated re-sends `MOVE`. DND hides others' emote bubbles locally and shows 🔕 on the name pill.
- Reader `state` is normalised from the backend's `FOCUS`/`READY`/`BREAK` by `toReaderState`.
- `MainLayout.vue` learns the current room via the `focus-room-updated` event + `localStorage`, not a shared store.
- **Map full screen** (`composables/sceneFullscreen.ts`, button top-left of the map): the scene shell is teleported to `body` (z 3000), the page is pinned (body fixed, scroll reset after rotating — the iPhone home-screen app pushes the page down 62px in landscape and touches miss). Browser Fullscreen API + `orientation.lock('landscape')` when available (Android); otherwise a portrait phone gets the map rotated 90° (`sceneRotated`; `localPoint` maps taps/joystick back). The rotated Safari case leaves a 72px strip for Safari's bottom bar; landscape and home-screen app don't. The timer/music dock is teleported into the rotor and collapses to a `⏱ 25:00` button (YouTubeTv is not moved: its iframe would reload). Joysticks cancel touch events (iOS ignores `touch-action: none`). Safari's own toolbar can't be hidden by the page.
- **Stale service worker**: the Vercel build used to be a PWA. `public/sw.js` replaces any old worker (clear caches, unregister, reload tabs); `build:pwa` (what Vercel runs) now ships the plain SPA plus that file.
- **Tab title / share image**: idle title is the site name, `⏳ mm:ss 專注中` while focusing; `public/og-image.png` (1200×630 pixel scene) is the og/twitter image (`utils/seo.ts`, `index.html`).

## Look: gender & accessories (10-16)
- `PlayerPrefs.body` (0 boy / 1 girl) and `acc` (`ACCESSORIES` id, 0 = none), `ownedAcc` (bought with coins in Settings; cloud merge unions it). Sent with JOIN/MOVE/POS via `myLook()`; backend clamps like hair/shirt.

## Whispers (10-16)
- Profile card → 6 preset phrases (`WHISPER_IDS` ↔ backend `allowedWhispers`), `WHISPER {to, phrase, username}`; backend rate-limits (3 s) and delivers only to the recipient's tabs in the room. Receiver shows a notify unless `whispersOff`, DND, or sender in `prefs.blocked`. Watch lives after `useLibrarySocket()` in IndexPage (TDZ bit us once).

## Transitions (v1.4.0, 10-18)
- `sceneTransition.ts` (`playTransition(kind, label, {line, up})`) + `SceneTransition.vue` mounted inside `.scene-rotor` (covers the map, follows fullscreen). Kinds: `mrt` (train in a tunnel, line colour red/green/orange), `elevator` (doors + floor display), `stairs` (footsteps), `home` (house, door opens), `loading` (island on waves).
